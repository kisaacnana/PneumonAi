# Contributing to PneumonAi

Thank you for your interest in improving PneumonAi.

## Development setup

1. Clone the repository.
2. Create and activate a Python virtual environment.
3. Install dependencies with `pip install -r requirements.txt`.
4. Keep datasets and generated model artifacts outside Git.
5. Run the test suite with `pytest -q`.

## Pull requests

- Keep changes focused and documented.
- Add or update tests when changing behavior.
- Do not commit datasets, trained models, credentials, or patient-identifiable information.
- Do not present experimental model results as clinical performance.
- Update the README when workflows or project structure change.

## Medical/ethical considerations

PneumonAi is an educational/research project. Contributions must not imply that the software is validated for diagnosis or clinical decision-making without appropriate evidence and regulatory review.
